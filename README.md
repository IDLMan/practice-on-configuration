# Эмулятор UNIX shell — вариант 21

Практическая работа № 1 по дисциплине «Конфигурационное управление».
Язык: Python 3.10+; сторонние зависимости не требуются.

## Этап 1: REPL

Консольный эмулятор повторяет цикл «ввод → разбор → выполнение → вывод».
Приглашение формируется по настоящему имени пользователя и компьютера.
Аргументы разбиваются **по пробелам**, без поддержки кавычек (по заданию).

Команды:

- `ls [аргументы]` — пока заглушка; выводит имя и список аргументов.
- `cd [аргументы]` — пока заглушка; выводит имя и список аргументов.
- `exit` — завершает работу, дополнительные аргументы дают ошибку.
- Неизвестные команды — сообщение `command not found`.

## Запуск и тестирование

В корне репозитория:

```bash
python3 -m src.main
python3 -m unittest discover -s tests -v
```

Linux/macOS: `./run.sh`; Windows: `run.bat`.

Пример интерактивного диалога (приглашение зависит от ОС):

```text
alice@host:~$ ls docs src
ls: arguments=['docs', 'src']
alice@host:~$ cd /tmp
cd: arguments=['/tmp']
alice@host:~$ wrong
wrong: command not found
alice@host:~$ exit extra
exit: arguments are not supported
alice@host:~$ exit
```

Разработка сохраняется отдельным коммитом этапа после прохождения тестов.
